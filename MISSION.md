# Mission: Build and understand The Secret Garden

## Why

Learn enough Next.js, React, TypeScript, and React Three Fiber to confidently shape The Secret Garden without treating its code as a black box.

## Success looks like

- Explain how the page, 3D scene, models, and controls connect.
- Change the garden's visuals and interactions without relying on copied code.
- Debug common rendering, state, and input problems independently.

## Constraints

- Learn through the real project rather than disconnected examples.
- Prefer plain-language explanations close to the relevant code.

## Out of scope

- Advanced 3D engine internals that the current garden does not use.
